## What's wired up

- **Frontend** — Vite, port `3170`. Proxies `/api` to the backend.
- **Backend** — Express + ts-node-dev, port `8170`.
- **Database** — Postgres `webappmonitor` on the i7's WSL2 instance.
- **Auth** — Firebase Google sign-in. Email allowlist in `server/.env` (`ALLOWED_EMAILS`).
- **Roles** — `admin`, `pro`, `guest`. `ADMIN_EMAILS` is the bootstrap-admin list.
- **Tunnel** — Cloudflare tunnel ingress rule for `webapp-monitor.uskiano.com`.
- **PM2** — entries in `F:/cloudflare/ecosystem.config.cjs`.

## Rollback (if you kill this project)

1. Remove PM2 entries from `F:/cloudflare/ecosystem.config.cjs` and `pm2 reload`.
2. Remove the ingress lines for `webapp-monitor.uskiano.com` from `~/.cloudflared/config.yml`.
3. Restart cloudflared service.
4. Remove the DNS record:
   `cloudflared tunnel route dns --overwrite-dns 3bab33c8-4282-4a1d-877d-e59c455e881d <other-hostname>`
   …or delete it in the Cloudflare dashboard (DNS tab → find the CNAME for `webapp-monitor.uskiano.com`).
5. Drop the DB:
   `wsl -d Ubuntu -- bash -c 'sudo -u postgres psql -c "DROP DATABASE webappmonitor; DROP USER webappmonitor;"'`
6. Remove the row from `F:/cloudflare/PORTS.md` (or mark it as freed).
7. Optionally archive/delete the GitHub repo.
